# 트랜잭션

- 트랜잭션은 Service 계층에서 관리한다.
- 조회 전용 Service 메서드에는 `@Transactional(readOnly = true)`를 사용한다.
- 생성·수정·삭제 메서드에는 `@Transactional`을 사용한다.
- 하나의 업무 처리는 하나의 트랜잭션으로 관리한다.
- 트랜잭션 안에서 불필요한 외부 API 호출이나 오래 걸리는 작업을 하지 않는다.
- 예약 정원 변경과 예약 저장은 정합성이 유지되도록 함께 처리한다.
- 동시성 제어가 필요한 로직은 락 또는 조건부 UPDATE 등을 검토하고 테스트한다.
